# FluxNode

FluxNode is a real-time data processing platform based on an event-driven architecture that aggregates streaming data feeds.

FluxNode is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- FluxNode is a real-time data
- processing platform based on an
- event-driven architecture that aggregates streaming

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/FluxNode.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

FluxNode is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
